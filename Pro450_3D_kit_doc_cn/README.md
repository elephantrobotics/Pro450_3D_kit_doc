# Pro450 3D套装使用说明

<img src="./img/450_1.png" style="zoom: 50%;" />

## 1. 套件概述
myCobot Pro 450是一款紧凑型一体式全谐波六轴机械臂。 谐波减速器、伺服电机、刹车与控制器集成于关节模组，无需额外配置控制柜，小体积也能搭建专业的机器人应用。 这一次，我们为它搭配了一台工业级 3D 相机。 不同于普通二维视觉，它能够获取物体的三维点云信息，不仅“看得见物体”，还可以判断物体在空间中的位置与姿态。 我们用一组随机摆放的 PVC 管件，搭建了一个典型的工业无序分拣实验。 完整验证工业视觉分拣中的三维感知、目标匹配、位姿计算和机器人抓取流程。 3D 相机首先采集场景点云，通过点云模板匹配识别不同类型的工件，并计算目标的空间位姿 机械臂根据识别结果移动至抓取位置，完成抓取，再将不同工件放入对应区域。 工件的类型、位置和朝向也不需要提前整齐摆放。 这正是工业无序分拣中，机器人从“看到”，到“理解空间”，再到“执行抓取”的完整逻辑。 从 3D 视觉到机器人控制，用一套桌面级平台，学习并验证真实的工业无序分拣流程。

## 2. 工作流程

程序启动后，将自动触发相机拍照，并对托盘内是否存在工件进行判断。若检测到工件，系统会根据视觉反馈获取工件的位姿与类别信息，控制机械臂完成抓取，并将其分类放置至相应位置。若未检测到工件，程序将自动结束运行。
